制定日: 2026年10月17日

取得する情報

本ツールは、Googleアカウントの許可を得て、お米戦隊マイマイマイのYouTubeチャンネルについて次の情報だけを読み取ります。

  • 動画ごとの再生数・平均視聴時間・高評価数・コメント数・共有数・登録者増加数
  • 視聴者の年齢層・性別・国・流入元の集計値（個人を特定できない統計）

利用目的と保存先

取得した情報は、動画内容の改善のために運営者のGoogleスプレッドシート（実績シート）にのみ保存します。

第三者への提供

取得した情報を第三者に提供・販売することはありません。

Google API の利用

本ツールによるGoogle APIから受け取った情報の使用は、Google API Services User Data Policy（限定使用の要件を含む）に従います。許可はGoogleアカウントの「サードパーティのアクセス」からいつでも取り消せます。
